# Pragmatic Agentic Development: Docs, Context and Workflow in Practice


This workshop is a pragmatic, opinionated approach to agentic development for solo developers and small teams. It starts from one rule: document first, agent oriented. Documentation and code evolve together, each change to one carries a change to the other, so the project always explains itself to the agents working on it. The docs are organized to be self-discovered and self-maintained, optimized for context handling.

We’ll work hands-on on a sample project, and we’ll let it evolve. You’ll understand how to make the documentation self-organizing, and complement it with a smart use of skills. Finally, you’ll adopt a workflow that is flexible in how you use it and rigid in its steps: a small fixed sequence of stages that keeps agents on track without turning into process overhead.

You’ll leave with an example approach that you can adapt to your own projects, and increased awareness of how agents behave, so you can make more efficient use of the tools at your disposal.

Takeaways:

- A good strategy to organize a project and its documentation.
- A self-organizing approach to docs that resists drift.
- Some examples of effective workflows.
- A better understanding of agentic coding, and not only coding

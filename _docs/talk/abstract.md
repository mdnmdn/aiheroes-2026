# Documentation Is the King: How to Rule Your Agents


Documentation used to be the task that slowed teams down: written late, read rarely, stale by the next release. In the agentic era it flips. Agents act on what is written, so docs now decide how fast and how well your AI delivers.

This talk shows how to turn documentation into a driver. We cover the practices that build a virtuous circle, where better docs lead to better agent output and cheaper upkeep, and how to optimize agent context with self-organizing documentation instead of bloated instruction files.

From hands-on experience, you’ll leave with practical tips on how to smartly build and organize documentation for both humans and agents.

§ 07 — Spec-first · cyber
07 / 10

Lock the signature first.
Let the body negotiate.

A spec-first prompt pins the surface area. The model can be wrong about the implementation; it can't be wrong about the shape, because the shape is already typed.

  • Pin types, return shapes, error cases
  • Show one canonical call site
  • Require tests against the spec
  • Iterate body, not signature
// 1. Lock the contract.
type Retrieval = {
  query: string, k: number,
  rerank: boolean
};
// 2. Model fills the body.
async function retrieve(r):
  Promise<Doc[]> {
  // @model: don't change sig
}
// 3. Tests assert shape.
expect(res).toHaveLength(5);
↳ the typer is the cheapest reviewer you have

§ 08 — Ten rules · acid
08 / 10

Ten rules of the house.

  1. i.
    Pin the contract first.
    Types and tests before tokens.
  2. ii.
    Diff, not prose.
    A patch is reviewable; a paragraph isn't.
  3. iii.
    One file ideally.
    Bigger blast radius needs more proof.
  4. iv.
    Revert is free.
    Use it before debugging the model.
  5. v.
    Curate context.
    Auto-attach is a smell, not a feature.
  6. vi.
    Read every diff.
    If you can't, the diff is too large.
  7. vii.
    Tests gate, types catch.
    Both run on every turn, no exceptions.
  8. viii.
    Memo what worked.
    A journal beats a clever prompt.
  9. ix.
    Ship the loop, not the prompt.
    Prompts age; loops compound.
  10. x.
    When in doubt, by hand.
    The model is an amplifier, not a substitute.
